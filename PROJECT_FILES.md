# Syllis V2 — Complete source archive

This archive contains the complete editable source code and configuration for the Syllis V2 demo.

## Start
1. Extract this folder.
2. Open the extracted `syllis-v2` folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open http://localhost:3000.

## Included
- app routes and pages
- reusable React components
- styling
- dark/light theme
- interactive cursor
- demo product/collection data
- Next.js/TypeScript/Tailwind configuration
- package manifest
- README
- gitignore

`node_modules` and `.next` are intentionally not included because they are generated dependencies/build output. `npm install` recreates the dependencies from `package.json`.
